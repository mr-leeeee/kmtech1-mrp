# KMTECH MRP 백업 / 복구 가이드 (단일 PC)

## 백업은 언제 만들어지나요?

| 시점 | 내용 |
|------|------|
| 저장할 때마다 | Excel을 저장할 때마다 `backup/YYYYMMDD/` 폴더에 자동 백업 생성 |
| 매일 자정 | 서버가 켜져 있으면 00:00에 자동 백업 생성 |
| 보관 기간 | **7일**. 7일이 지난 폴더는 자동 삭제 |

백업 파일 위치 예시:
```
C:\vibecode\kmtech1\backup\20260920\shelf_MRP_개선판.xlsx.20260920_120000.bak
                      └ 일자 폴더 └ 원본파일명.생성시각.bak
```

## 시스템이 멈췄거나 Excel이 손상됐을 때

### 1단계: 가장 최근 백업 찾기
`backup` 폴더에서 **가장 최신 날짜 폴더**로 들어가세요.
폴더 안의 `.bak` 파일 이름에 생성 시각이 있어서 가장 마지막 시각 파일이 최신 데이터입니다.

### 2단계: 복원
1. KMTECH MRP 서버가 켜져 있으면 **먼저 종료**합니다.
2. 손상된 `shelf_MRP_개선판.xlsx`를 다른 이름으로 옮겨둡니다 (예: `shelf_MRP_개선판_손상.xlsx`).
3. 최신 `.bak` 파일을 복사해서 원래 자리에 `shelf_MRP_개선판.xlsx`라는 이름으로 붙여넣습니다.
4. 서버를 다시 실행합니다. 프로그램이 정상적으로 데이터를 읽어옵니다.

### 3단계: 복원 결과 확인
- 브라우저에서 `http://127.0.0.1:8000` 접속
- KPI와 재고 수치가 정상 표시되는지 확인
- 문제가 있으면 좀 더 오래된 백업(전날 폴더)으로 다시 복원

## 하루 일과 마지막에

- 서버를 **정상 종료**하세요. 종료 시 자동으로 Excel에 저장됩니다.
- 전원 차단으로 꺼지면 저장되지 않은 마지막 변경분은 손실됩니다.
- 주 1회 이상 `backup` 폴더를 USB나 외장하드에 복사해 두면 안전합니다.

## 절대 하지 말 것

- **프로그램이 켜져 있는 동안 Excel 파일을 직접 열지 마세요.** 파일이 잠겨 있고, 열어서 건드리면 저장이 꼬입니다.
- 백업 폴더를 임의로 삭제하지 마세요.
- Excel 파일을 다른 폴더로 이동하지 마세요. 실행 폴더에 있어야 합니다.
