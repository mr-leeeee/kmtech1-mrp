# KMTECH MRP 사용설명서

## 시작 방법
1. PowerShell 실행: `.\start_mrp.ps1`
2. 브라우저 접속: http://127.0.0.1:8000

## 메뉴
- 대시보드: KPI 요약
- 품목 기준정보: 마스터 관리
- 생산: 양품 생산 등록
- 완제품 출하: 출하 등록 및 현재고 확인
- 원부자재 발주: 자동 발주 및 일괄 출력
- 로그: 거래 내역 조회

## 주요 기능
- 자동 발주: 재고 부족 품목 자동 계산
- 선택 일괄 출력: 체크박스로 여러 발주서 한 번에 출력
- 완제품 현재고: 생산 - 출하 자동 계산

## 백업
- 자동 백업 폴더: backup/YYYYMMDD
- 7일 자동 삭제

## 주의사항
- Excel 파일 직접 수정 금지
- 단일 사용자 기준
- 종료 시 서버를 정상 종료해야 백업 완료
