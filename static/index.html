도움말

시작 방법

1. PowerShell 실행: .\start_mrp.ps1

2. 브라우저 접속: http://127.0.0.1:8000

주요 메뉴

대시보드: KPI 요약, 재고 현황, 발주 대기 수량

품목 기준정보: 품목 마스터 관리

생산: 생산실적 등록 버튼 → 완제품 생산량 입력, 양품/불량 분리

완제품 출하: 완제품 출하 등록 탭에서 출하 전표 생성, 현재고 자동 차감

원부자재 발주: 자동 일괄 발주 버튼으로 부족 품목 자동 발주, 체크박스로 선택 일괄 출력

로그: 생산/입출고/발주 거래 내역 조회 및 수정/삭제

백업 및 주의사항

• 자동 백업 폴더: backup/YYYYMMDD, 7일 유지

• Excel 파일 직접 수정 금지

• 단일 사용자 기준, 종료 시 정상 종료 필요
