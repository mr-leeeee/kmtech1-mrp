KMTECH MRP v1.2 포터블 실행 안내

1. KMTECH_MRP.exe 를 더블클릭합니다.
2. 처음 실행 시 실행 파일이 있는 폴더에 shelf_MRP_개선판.xlsx 가 자동 생성됩니다.
   - 이후 모든 변경사항은 이 Excel 파일에 저장됩니다.
3. 브라우저에서 http://127.0.0.1:8000 접속

주의사항
- 실행 파일과 Excel 파일이 같은 폴더에 있어야 합니다.
- Windows Defender가 차단할 수 있으니 허용해 주세요.
- 다른 컴퓨터에서 실행 시 .NET Framework / Visual C++ Redistributable 필요 없음 - PyInstaller로 동적 링크 포함됨.
